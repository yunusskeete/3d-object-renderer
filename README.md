# 3d-object-renderer
Blender 3D Object Rendering for 3D Agentic RAG.

## Overview
This repo implements a simple microservice for 3D asset rendering using blender python for AI-enabled 3D automation.
Functionality is provided to:
1. Ingest 3D files (of a variety of file formats) and produce multi-view renderings, asset metadata, and, optionally, depth and disparity maps.

This functionality is exposed via REST API endpoints.
